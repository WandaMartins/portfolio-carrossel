# Portfólio com Carrossel

🔗 Acesse o projeto: https://wandamartins.github.io/portfolio-carrossel/

## 📌 Sobre
Projeto de interface web interativa com implementação de carrossel utilizando JavaScript, permitindo navegação entre elementos visuais.

## 🚀 Tecnologias
- HTML
- CSS
- JavaScript

## 🎯 Objetivo
Praticar manipulação do DOM e criação de interatividade em páginas web.

## 📌 Funcionalidades
- Carrossel interativo
- Navegação entre elementos
- Layout responsivo
